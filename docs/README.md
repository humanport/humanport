# HumanPort documentation

This documentation is public and versioned alongside the code.

Planned contents:

- **Concepts** — `HumanRequest`, interaction types, subjects, actors, tenancy.
- **Protocols** — REST + OpenAPI, the stateless MCP adapter, the A2A service and
  bridge.
- **Operating HumanPort** — Docker Compose self-hosting, configuration,
  observability, backup and retention.
- **Security** — authentication, authorization, request integrity, idempotency,
  audit architecture.
- **Extending HumanPort** — routing, policy, notification channels and the
  extension interfaces.

Documentation is written for people outside the project. If a page only makes
sense to someone with access to internal context, it belongs somewhere else.
